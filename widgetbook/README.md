# Sampath Widgetbook

Catalogue for `sampath_ds`. Switch Light / Dark with the **Theme** addon
(right panel → Addons).

```sh
cd widgetbook
flutter run -d chrome    # or: -d macos
```

One use case per component variant (see CLAUDE.md). Foundations pages read
the token maps (`byFigmaName`), so they update when tokens are regenerated.
